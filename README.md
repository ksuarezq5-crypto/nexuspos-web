# Web de VentaPro

La versión publicada está en `site/` y corresponde al contenido compilado del archivo `dist.rar` proporcionado para actualizar la página. Incluye la página principal y la demo en `/demo/`.

Netlify publica directamente esa carpeta, sin recompilar el proyecto anterior. Los archivos de `src/` se conservaron como referencia, pero no corresponden al código fuente de esta nueva versión y no se utilizan en el despliegue.

Para actualizar esta versión, reemplaza el contenido de `site/` con una nueva distribución compilada, conservando la estructura de carpetas de sus recursos y de la demo.
